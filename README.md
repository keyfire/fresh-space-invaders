# Космические жуки

Аркадная игра в стиле Space Invaders на чистом HTML5 Canvas. Один самодостаточный файл – без сборки, зависимостей и внешних ассетов.

🎮 **Играть в Telegram:** <https://t.me/kosmozhuki_bot/play>
🌐 Веб-версия: <https://keyfire.github.io/fresh-space-invaders/>

Отбивайся от волн космических жуков, лови призы и качай корабль на боссах – и пробивайся в глобальный топ. Побил рекорд? Поделись карточкой результата с друзьями и позови их обгонять 👾

## Управление

| Действие | Клавиатура | Мышь / тач |
|----------|-----------|------------|
| Движение | ← → (или A / D) | Курсор / палец |
| Выстрел  | Пробел | Клик / тап |

Одним пальцем: повторный тап по треку движения – выстрел; удержание при стреляющем призе – авто-поток.

## Возможности

- Призы с жуков: тройной и двойной выстрел, щит, заморозка, очередь, лишняя жизнь
- Боссы каждые 5 уровней, а за победу корабль получает апгрейд навсегда: крылья с пушками, дроны, пробивные пули, магнит-щит
- Глобальный рейтинг в Telegram и шаринг карточкой результата
- Локализация на 5 языков: RU / EN / ES / PT / TR
- Пиксельная графика, взрывы на частицах, неоновое свечение, звук на Web Audio (синтез на лету, без файлов)
- Прогрессия сложности: с уровнями враги быстрее и чаще стреляют, появляются бронированные жуки

## Запуск локально

Просто откройте `index.html` в браузере – или раздайте папку любым статическим сервером:

```bash
python -m http.server 8000
# затем http://localhost:8000
```
